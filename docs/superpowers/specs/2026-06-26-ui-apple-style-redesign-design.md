# UI 深度重构设计文档 - Apple 极简奢华风格

**日期：** 2026-06-26
**目标：** 将个人作品集网站重构为 Apple 风格的极简奢华设计

---

## 1. 设计目标

将现有的 UI 界面优化为类似 Apple 官网的极简奢华风格，突出高级感和专业感。

### 核心原则
- **极简主义**：移除不必要的装饰元素，让内容成为焦点
- **精致细节**：通过阴影、圆角、间距等细节体现品质感
- **清晰层次**：使用字体大小、字重、颜色建立清晰的视觉层次
- **呼吸留白**：增加元素间距，让页面更透气

## 4. 组件改动详情

### 4.1 Hero 区域 (`src/components/Hero.tsx`)

#### 改动内容
1. **移除装饰性背景文字**：删除 "AI PRODUCT MANAGER STRATEGIST INNOVATOR" 文字
2. **简化背景效果**：
   - 移除网格图案
   - 保留 1-2 个柔和光晕（降低透明度）
   - 背景色改为纯白 `#ffffff`
3. **调整布局**：
   - 增加内边距，让内容更居中
   - 头像区域改为圆形渐变背景
4. **按钮样式**：
   - 改为胶囊形 `border-radius: 980px`
   - 背景改为深灰 `#1d1d1f`
   - 增加内边距 `padding: 16px 40px`

#### 保留内容
- 整体布局结构（左文右图）
- 字体 Jost
- 绿色主题色点缀

---

### 4.2 项目卡片 (`src/components/Projects.tsx`)

#### 改动内容
1. **移除边框**：删除 `border` 属性
2. **添加阴影**：`box-shadow: 0 4px 20px rgba(0, 0, 0, 0.06)`
3. **增加圆角**：`border-radius: 18px`
4. **优化内边距**：`padding: 24px`
5. **标签样式**：
   - 改为胶囊形 `border-radius: 20px`
   - 背景改为 `#f5f5f7`
6. **添加悬浮效果**：
   - `transform: translateY(-4px)`
   - 阴影加深

## 7. 注意事项

1. **保持功能不变**：只改视觉，不改功能逻辑
2. **渐进式改动**：按组件逐步修改，每改一个组件测试一次
3. **Dark Mode 兼容**：确保所有改动在 Dark Mode 下也正常
4. **响应式适配**：确保在移动端也有良好体验
